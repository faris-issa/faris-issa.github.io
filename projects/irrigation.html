Project 02 / Senior capstone

Smart Irrigation System

My senior capstone team, Moisture Magic, developed an automated irrigation system that uses soil moisture readings to control watering.

Senior capstone · Moisture Magic · Team project

Arduino Sensors Fluid systems

Project overview

My work

System design

Our system uses an Arduino UNO R4 WiFi, soil moisture sensors, a solenoid valve, drip irrigation hardware and a flow meter. We also built a hand-watered control setup for comparison.

My contributions

I worked on assembling the system, wiring the sensors and solenoid, and testing the valve response at different soil moisture levels. I helped address fitting issues and worked on collecting flow and moisture data.

Testing

During a rain event, we observed that the valve stayed closed rather than supplying additional water. We added flow logging to support a comparison with the hand-watered setup.
